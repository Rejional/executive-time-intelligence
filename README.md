# Executive Time Intelligence

Executive Time Intelligence is a prototype for an executive memory and time-intelligence platform. The app reconstructs an executive's workday from calendars, email, collaboration tools, documents, calls, travel, voice notes, and manual corrections, then organizes activity into meaningful work streams.

The goal is not payroll-style time tracking. The goal is executive self-awareness: helping leaders understand where attention is going, how time aligns to strategic priorities, where operational drag is emerging, and what changes could improve leadership effectiveness.

## Prototype

Open `index.html` in a browser to use the static prototype.

The current prototype includes:

- Daily attention brief
- Reconstructed timeline with evidence and confidence
- Simulated source ingestion
- Voice reflection capture
- Manual correction, split, merge, private, and exclude controls
- Weekly intelligence view
- Work-stream clustering
- Executive coaching recommendations
- Operating model setup
- Privacy controls and audit trail
